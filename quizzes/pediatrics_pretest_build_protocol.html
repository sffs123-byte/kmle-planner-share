소아 Pretest 제작 프로토콜

1·2·3주차 pretest 퀴즈를 만들 때 사용한 방식. 핵심은 문제 수 맞추기가 아니라 source trace, uncertain 보존, 이미지 누설 방지, Allen 근거, live QC까지 닫는 것이다.

Source-first Uncertain 보존 이미지 front/answer 분리 GitHub Pages 배포

한 줄 결론

  1. source inventory 먼저 만든다.
  2. 현재 deck에 audit layer를 덧씌운다.
  3. 불완전 복기는 삭제하지 않는다.
  4. 이미지는 답 누설 여부로 front/answer 분리한다.
  5. HTML 재생성 후 live QC까지 본다.

1

표준 제작 순서

1

Source inventory

소아 폴더 전체에서 pretest, 프테, HI, 야마, 2023, 2025, 2026 파일을 찾고 파일별 문항 수·이미지 수·우선순위를 기록한다.

2

현재 deck 스냅샷

JSON 카드 수, source 분포, uncertain 수, 이미지 수, 단원 분포를 먼저 찍는다. 기존 deck은 함부로 버리지 않는다.

3

Coverage audit

최신 2026 → 2025 누적 → 2023 PDF → HI/Yama 순서로 현재 deck에 포함/부분/누락/수동확인/이미지 필요를 판정한다.

4

누락·variant 반영

같은 답이라도 stem, 선지, 이미지가 다르면 variant로 보존한다. 기존 ID 안정성은 유지하고 append 중심으로 처리한다.

5

Uncertain 재분류

원문에서 확정 가능한 것은 정답을 확정하고, 불완전 복기는 추정 답안을 붙이되 uncertain/source note를 유지한다.

6

이미지 audit

front-safe, answer-only, exclude로 나눈다. 정답·진단명·해설이 보이는 crop은 앞면 금지.

7

Allen 근거 해설

Allen corpus를 고정하고 batch로 나눠 allen_answer, allen_explanation, allen_refs, confidence를 붙인다.

8

Generate → QC → Push

generator로 HTML 재생성, JSON/DOM/live/mobile/image QC를 통과한 뒤 GitHub Pages에 push한다.

9

10분팩

deck과 별도로 시험 직전용 10분팩을 만든다. 최신 exact 문항, high-yield lock, hard-uncertain 답 고정 금지 목록을 담는다.

3

카드화 규칙

Core rule

  • 문제 1개 = 카드 1개.
  • stem/선지/이미지가 다르면 같은 답이라도 variant로 보존.
  • 불완전 복기 문항은 삭제하지 않고 uncertain으로 남김.
  • 기존 카드 번호/ID 안정성 유지.

불완전 복기 처리

  • uncertain: true
  • answer: 추정 답안... 또는 원문 확인 필요
  • raw_anchor, source, needs_original_source 유지
  • 시험 직전에는 답 고정 금지 목록으로 따로 관리
금지: 원문이 불완전하다고 카드를 삭제하거나, 이미지/선지 확인이 필요한 답을 확정처럼 보여주는 것.
4

이미지 원칙

Front-safe

문제 풀이 자체에 필요한 CXR, EEG, MRI, 피부 병변, 갑상샘 스캔 등. 답/진단명/체크 표시가 없어야 한다.

Answer-only

정답 표시, 해설, 진단명, 답 체크가 포함된 원문 crop. 뒷면/해설 참고용으로만 표시한다.

Exclude

다른 문제 이미지, 오염 crop, 답 누설이 심한 캡처, 텍스트로 이미 충분한 screenshot.

3주차 실제 반영

최종 v7 기준 image refs 8개. front-safe 4개, answer-only 4개로 분리했다.

5

Allen PDF 기준 해설

Allen source corpus를 Needle - 소아과/source/pages/*.md 65쪽으로 고정하고, 309문항을 30문항 × 10 batch + 잔여 9문항으로 나누어 해설을 붙였다.

필드

  • allen_answer
  • allen_explanation
  • allen_refs
  • allen_confidence
  • allen_needs_original_source
  • allen_notes

판정

  • high: Allen 근거가 직접적
  • medium: 근거는 있으나 원문 복기 보정 필요
  • low: 원문/이미지 확인 필요

주의

low confidence 또는 needs_original_source 문항은 시험 직전 확정답처럼 고정하지 않는다.
