## Part A: 국민건강증진법 (25Q)

### A-1. 총론 — 종합계획·실행계획·영양조사

| 항목 | 주체 | 주기 | 비고 |
|---|---|---|---|
| **종합계획 수립** | 보건복지부장관 | **5년마다** | 국민건강증진정책심의위원회 심의 |
| **실행계획 수립·시행** | 보복부장관 + 관계중앙행정기관장 + 시도지사 + 시장군수구청장 | **매년** | 종합계획 기초 |
| **국민건강영양조사** | **질병관리청장** (보복부장관과 협의) | **매년** | 건강상태·식품섭취·식생활 조사 |
| **건강 허위광고 시정/금지** | 보건복지부장관 | — | 검증 안 된 건강비법·심령술 광고 |

**국민건강증진사업 정의 6가지**: 보건교육, 질병예방, 영양개선, **신체활동장려**(2021 신설), 건강관리, 건강생활실천

> 함정: 영양조사 주체를 "보건복지부장관"으로 바꿈 → 질병관리청장이 정답

### A-2. 금주를 위한 조치

**주류 용기 경고문구 (법정 2가지)**:
1. "과다한 음주는 건강에 해롭다"
2. "임신 중 음주는 태아의 건강을 해칠 수 있다"

| 항목 | 내용 |
|---|---|
| 경고문구 표기 의무자 | 주류 제조면허자 / 수입판매자 |
| 주류광고 가능자 | **주류 제조면허자·판매업면허자·수입자만** (그 외 광고 금지) |
| 주류광고 금지 내용 | 경품제공 표시, 임산부·미성년자 묘사, 운전 중 음주 묘사, 체력·운동능력 향상 표현 |
| 광고 위반 시 | 보건복지부장관이 시정 요구 또는 금지 명령 |
| **금주구역 지정** | **지방자치단체가 조례로** 지정 |
| 알코올 남용·의존 실태조사 | 보건복지부장관이 **5년마다** (정신건강 실태조사와 연계) |
| 음주폐해예방위원회 | **보건복지부장관** 소속 |

> 함정: 금주구역 지정 주체를 "보건복지부장관"으로 바꿈 → 지방자치단체(조례)가 정답

### A-3. 금연을 위한 조치 (최다 출제)

#### 금연구역 체계

| 구분 | 대상 | 근거 |
|---|---|---|
| **시설 전체 금연** (제9조 ④항) | 26개 유형 공중이용시설 | 소유자·관리자 의무 |
| **경계선 30m 이내** (제9조 ⑥항) | 유치원, 어린이집, 초·중·고등학교 | 시장·군수·구청장 지정 |
| **공동주택 금연** (제9조 ⑤항) | 복도·계단·엘리베이터·지하주차장 | 거주 세대 **2분의 1 이상** 신청 |
| **조례 금연구역** (제9조 ⑦항) | 관할구역 일정 장소 | 지방자치단체 |

#### 주요 시설 금연 범위 비교

| 시설 | 금연 범위 |
|---|---|
| 유치원·초중고 (초중등교육법) | **교사 + 운동장 등 모든 구역** |
| 대학 (고등교육법) | **교사만** (운동장 제외) |

#### 흡연실 설치 위치

| 반드시 **실외** 설치 | 실내 설치 가능 (부득이한 경우) |
|---|---|
| 유치원, 초중고, 의료기관, 어린이집, 청소년시설, 도서관, 어린이놀이시설, 어린이운송용차량 | 위 8종 외 기타 시설 (밀폐 공간 + 환풍기 필수) |

#### 담배갑 경고그림·경고문구

| 항목 | 기준 |
|---|---|
| 경고그림 + 경고문구 합계 | 포장지 넓이의 **50% 이상** |
| 경고그림 단독 | 앞면·뒷면 **각 30% 이상** |
| 포함 발암성물질 (6가지) | **나**프틸아민, **니**켈, **벤**젠, **비**닐크롤라이드, **비**소, **카**드뮴 |
| 금연상담전화번호 | 반드시 표기 |

#### 담배자동판매기
- 설치 장소: 19세 미만 출입금지 장소, 점포 내부, 흡연실
- **성인인증장치** 상시 부착 의무

> 함정: 경계선 거리를 "50m"로 바꿈 → 30m가 정답 / 경고그림 면적을 "30%"로 바꿈 → 50% 이상이 정답

### A-4. 국민건강증진기금

**기금 재원**: 담배부담금 + 기금 운용수익금 (건강보험료 아님!)

#### 담배 부담금 주요 금액

| 담배 유형 | 부담금 |
|---|---|
| **궐련** | 20개비당 **841원** |
| 궐련형 전자담배 | 20개비당 750원 |
| 니코틴 용액 전자담배 | 1mL당 525원 |
| 물담배 | 1g당 1,050.1원 |

#### 부담금 부과·징수 절차 (기한 정리)

| 단계 | 기한 |
|---|---|
| ① 반출자료 제출 | 다음 달 **15일**까지 |
| ② 납부고지 | 자료 제출받은 날부터 **5일 이내** |
| ③ 납부 | 납부고지 받은 달 **말일**까지 |
| ④ 체납 독촉장 | 납부기한 경과 후 **10일 이내**에 **30일 이상** 기간 정하여 발부 |
| ⑤ 강제징수 | 국세체납처분의 예 |

#### 기금 사용 용도 12가지

1. 금연교육·광고, 흡연피해 예방·흡연피해자 지원
2. 건강생활 지원사업
3. 보건교육 및 자료 개발
4. 보건통계·조사연구·개발
5. 질병 예방·검진·관리 및 **암 치료**
6. 국민영양관리사업
7. 신체활동장려사업
8. 구강건강관리사업
9. 시도지사·시장군수구청장 건강증진사업
10. 공공보건시설·장비 확충
11. 기금 관리·운용 경비
12. 대통령령 정하는 사업

> 함정: 기금 재원에 "건강보험료"를 포함 → 재원은 담배부담금 + 운용수익금만

| 대한적십자사 | **O** |

| 항목 | 내용 |
|---|---|

- 매매 사실 알고도 채혈/수혈 시 처벌

| 수혈비용 보상 | 보건복지부장관이 헌혈환급적립금에서 의료기관에 보상 |
| 헌혈환급예치금 납부 | 원칙: **보건복지부장관**, 위탁 시 대한적십자사 회장 |

### B-2. 헌혈자 관리 (최다 출제)

#### 채혈 전 혈액원 의무
1. **신원확인**: 사진 있는 신분증 (단체헌혈은 관리감독자 확인 가능)
2. **건강진단**: 문진·시진·촉진, 체온, 맥박, 체중, 혈압, 빈혈검사

#### 건강기준 (채혈금지)

| 항목 | 기준 |
|---|---|
| 체중 | 남 **50kg** 미만, 여 **45kg** 미만 |
| 체온 | **37.5℃** 초과 |
| 수축기혈압 | **90 mmHg 미만** 또는 **180 mmHg 이상** |
| 이완기혈압 | **100 mmHg 이상** |
| 맥박 | **50회 미만** 또는 **100회 초과** |

#### 감염병별 채혈금지 기간 ★★★

> 암기법: **MBSB = 3-2-1-0.5**

| 감염병 | 금지 기간 |
|---|---|
| **말**라리아 | 치료종료 후 **3년** |
| **브**루셀라 | 치료종료 후 **2년** |
| **매**독 | 치료종료 후 **1년** |
| 급성 **B**형간염 | 완치 후 **6개월** |
| 만성B·C간염, HIV, CJD 등 | **영구** 금지 |

#### 약물별 채혈금지 기간

| 약물 | 금지 기간 |
|---|---|
| 이소트레티노인, 피나스테라이드 | **4주** |
| 두타스테라이드 | **6개월** |
| B간염 면역글로불린, 태반주사 | **1년** |
| 아시트레틴 | **3년** |
| 에트레티네이트, 소유래인슐린, 뇌하수체성장호르몬 | **영구** |

#### 예방접종 후 헌혈금지 기간 ★★★

| 기간 | 백신 | 암기법 |
|---|---|---|
| **24시간** | 콜레라, 디프테리아, 인플루엔자, A형간염, B형간염, 주사용 장티푸스, 주사용 소아마비, 파상풍, 백일해, 일본뇌염, 신증후군출혈열, 탄저, 공수병 | 불활화/주사용 백신 대부분 |
| **2주** | 홍역, 볼거리, 황열, 경구용 장티푸스, 경구용 소아마비 | **볼빨간(홍) 장황소** |
| **4주** | 풍진, 수두, BCG | **풍수지(리)** → 풍·수·B(CG) |

> 함정: 홍역을 "24시간"에 넣거나 BCG를 "2주"에 넣음 → 풍진/수두/BCG = 4주

#### 채혈 종류별 연령·간격

| 채혈 종류 | 최소 연령 | 다음 채혈까지 간격 |
|---|---|---|
| **320mL 전혈** | **16세** 이상 | 8주 (전혈→전혈) |
| **400mL 전혈** | **17세** 이상 | 8주 |
| **성분채혈** | **17세** 이상 | 혈장/혈소판혈장/두단위혈소판 **14일**, 백혈구/한단위혈소판 **72시간** |
| 두단위적혈구 | — | **16주** |

**연간 한도**: 전혈 **5회** 이내, 성분채혈 **24회** 이내

**65세 이상**: 60~64세 사이 헌혈 경험 있는 자만 가능

**임신·분만·유산**: 후 **6개월** 금지 (단, 본인 신생아 수혈 목적은 예외)

### B-3. 부적격혈액

#### 혈액선별검사 6종 ★★★

| 검사항목 | 검사방법 | 부적격기준 |
|---|---|---|
| **B형간염** | HBsAg + HBV NAT | 양성 |
| **C형간염** | HCV Ab + HCV NAT | 양성 |
| **HIV** | HIV Ab + HIV NAT | 양성 |
| **HTLV** I/II (**혈장성분 제외**) | HTLV I/II Ab | 양성 |
| **매독** | — | 양성 |
| **ALT** (수혈용만) | — | **≥ 101 IU/L** |

> 함정: "AST"를 선별검사에 포함 → ALT만 해당 (AST 아님!) / ALT 기준을 "51 IU/L"로 바꿈 → 101 IU/L

#### 기타 부적격혈액
1. 채혈과정 응고·오염
2. 심한 혼탁·변색·용혈
3. 용기 밀봉·표지 파손
4. 보존기간 경과
5. 채혈금지대상자 채혈분

#### 부적격혈액 발견 시 조치

| 상황 | 조치 |
|---|---|
| 발견 즉시 | 격리보관(잠금장치 별도 공간) → **폐기처분** + **보건복지부장관 보고** |
| 출고 후 발견 | 해당 의료기관에 **즉시 통보** + 폐기처분 조치 |
| 수혈사고 위험/발생 | **수혈받은 사람**에게 통보 |

#### 검사결과 헌혈자 통보

| 검사 | 통보 여부 |
|---|---|
| HBV, HCV, HTLV, 매독, ALT | **통보함** |
| **HIV** | **통보하지 않음** (감염 검사 목적 헌혈 방지) |

**예외 사항**:
- 부적격혈액을 **예방접종약 원료**로 사용 시 폐기 면제
- 섬 지역 긴급수혈/기상악화 시 NAT + HTLV 결과 수혈 후 확인 가능
- 헌혈자 본인 수혈용 채혈 시 검사 생략 가능

### B-4. 특정수혈부작용

#### 특정수혈부작용 범위 (5가지)
1. 사망
2. 장애 (장애인복지법상)
3. 입원치료를 요하는 부작용
4. 바이러스 등에 의한 감염질병
5. 의료기관장이 유사하다고 판단하는 부작용

#### 신고 절차 ★★★

```
의료기관의 장 → 보건소장 → 시·도지사 → 보건복지부장관
```

| 신고 주체 | 경로 | 기한 |
|---|---|---|
| 의료기관의 장 | → 보건소장 → 시도지사 | 확인일부터 **15일 이내** (사망: **지체 없이**) |
| 시도지사 | → 보건복지부장관 | 매월 말일 기준 다음 달 **10일**까지 (사망: **지체 없이**) |

> 함정: 보건소장을 생략하거나 "7일 이내"로 바꿈 → 반드시 보건소장 경유, 15일 이내

#### 보상금

| 항목 | 내용 |
|---|---|
| 지급 주체 | **혈액원** |
| 보상금 범위 | 진료비, 장애일시보상금, 사망일시보상금, 장제비, 일실소득, 위자료 |

## Part C: 연명의료결정법 (14Q)

### C-1. 연명의료계획서 vs 사전연명의료의향서 비교표 ★★★

| 구분 | 연명의료계획서 | 사전연명의료의향서 |
|---|---|---|
| **작성 주체** | **담당의사** (환자 요청으로) | **19세 이상 본인** (직접) |
| **작성 장소** | 의료기관 | 등록기관 (복지부장관 지정) |
| **대상** | 말기환자등 | 19세 이상 누구나 |
| **설명 의무자** | 담당의사 → 환자 | 등록기관 → 작성자 |
| **변경·철회** | 환자가 **언제든지** 요청 | 작성자가 **언제든지** 요청 |
| **등록·보관** | 의료기관의 장 | 등록기관 |
| **효력 상실** | — | 아래 4가지 사유 |

#### 사전연명의료의향서 효력 상실 사유 (4가지)
1. 본인이 직접 작성하지 않은 경우
2. 자발적으로 작성하지 않은 경우
3. 설명·확인이 미비한 경우
4. **연명의료계획서를 재작성한 경우** (→ 이때부터 효력 상실, 계획서가 우선)

### C-2. 환자 의사 확인 3경로 (제17조) ★★★

```
┌─────────────────────────────────────────────────────────┐
│                  임종과정 환자 판단                        │

└───────────────────┬─────────────────────────────────────┘
                    ▼
         ┌── 1순위: 연명의료계획서 있는가? ──┐
         │                                   │
        YES                                  NO
         │                                   ▼
    그 자체로              ┌── 2순위: 사전연명의료의향서 있는가? ──┐
    환자 의사              │                                       │
                         YES                                      NO
                          │                                       ▼
                  의사능력 있으면:              ┌── 3순위: 가족 진술 ──┐
                  담당의사가 환자에게 확인         │                     │
                  의사능력 없으면:              19세 이상 가족

                                              + 담당의사 + 전문의 1명

                                              가족 범위 순서:
                                              배우자 → 직계비속 →

```

### C-3. 환자 의사 확인 불가 시 (제18조)

| 대상 | 요건 |
|---|---|
| **미성년자** | 법정대리인(친권자) 의사표시 + 담당의사 + 전문의 1명 |
| **성인** | 가족 **전원** 합의 + 담당의사 + 전문의 1명 |

**성인 가족 범위**: 배우자 + 1촌 직계존비속 → 없으면 2촌 이내 → 없으면 형제자매

> 핵심 구분: 제17조 = 가족 **2명 이상 일치** / 제18조 = 가족 **전원 합의**
