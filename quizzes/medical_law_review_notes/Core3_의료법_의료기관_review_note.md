## 1. 의료기관 [종별 구분, 병상수 기준]

### Switch Map

| 축 | 내용 |
|---|---|
| **주체** | 보건복지부장관 (상급종합병원·전문병원 지정·재지정) |
| **대상** | 종합병원 중 요건 충족 → 상급종합병원; 병원급 중 난이도 높은 병원 → 전문병원 |
| **행위** | 종별 분류, 병상수·진료과목 요건 충족, 3년마다 평가·재지정 |
| **처분** | 전문병원 거짓 지정 → **필요적 취소**; 요건 미충족·자진 취소 → 임의적 취소 |

### 종별 분류 체계

```
의원급 (외래환자 중심)
 ├─ 의원
 ├─ 치과의원
 └─ 한의원

조산원 (조산사)

병원급 (입원환자 중심, 30병상 이상)
 ├─ 병원
 ├─ 치과병원
 ├─ 한방병원
 ├─ 요양병원 (요양병상)
 ├─ 정신병원 (2021.3.5~ 별도 종별)
 └─ 종합병원 (100병상 이상)
      └─ 상급종합병원 (보건복지부장관 지정)
```

### 종합병원 필수 진료과목 비교

| 구분 | 100~300병상 | 300병상 초과 |
|---|---|---|
| 내외산소 | 중 **3개** | **전부 (4개)** |
| 영상의학과 | O | O |
| 마취통증의학과 | O | O |
| 진단검사의학과 or 병리과 | O | O |
| 정신건강의학과 | X | **O** |
| 치과 | X | **O** |
| **합계** | **7개** 이상 | **9개** 이상 |

### 상급종합병원 vs 전문병원

| 항목 | 상급종합병원 | 전문병원 |
|---|---|---|
| 모체 | 종합병원 | 병원급 의료기관 |
| 지정 주체 | 보건복지부장관 | 보건복지부장관 |
| 재지정 주기 | **3년** | **3년** |
| 진료과목 | **20개** 이상 | 보건복지부령 기준 |
| 전문의 수련기관 | **필수** | 요건 아님 |
| 거짓 지정 시 | 취소 가능 | **필요적 취소** |

### 요양병원 입원 대상 제외

- 감염병환자 → **입원 불가**
- 정신질환자 → **입원 불가**
- 단, **노인성 치매**는 정신질환자 제외의 **예외** → 입원 가능

### 시험장 판단 문장
- "150병상 종합병원 필수 진료과목?" → 300 이하이므로 내외산소 중 3 + 영마 + 진or병 = **7개**
- "상급종합병원 지정 주체?" → **보건복지부장관** (시·도지사 아님)
- "전문병원 재지정 주기?" → **3년** (5년 아님)

### 함정 패턴
1. 30병상 → 50병상으로 변조
2. 100병상 → 200병상으로 변조
3. 300병상 이하인데 9개, 300병상 초과인데 7개로 뒤바꿈
4. 300병상 이하에서 "내외산소 전부 필수"라고 함정 (실제는 중 3개)
5. 재지정 3년 → 5년으로 변조
6. 상급종합병원 지정 주체를 시·도지사로 변조

## 2. 의료기관 개설 [신고 vs 허가, 개설 자격]

### Switch Map

| 축 | 내용 |
|---|---|
| **주체** | 의사·치과의사·한의사·조산사 / 국가·지자체 / 의료법인 / 비영리법인 / 준정부기관·지방의료원·한국보훈복지의료공단 |
| **대상** | 의원급 → **시장·군수·구청장에게 신고**; 병원급 → **시·도지사에게 허가** (의료기관개설위원회 심의) |
| **의무** | 시설기준·안전관리·운영기준·의료인 정원 준수, 수술실 CCTV 설치, 비급여 진료비용 고지 |
| **기한** | CCTV 영상: **30일** 이상 보관; 안전관리책임자 교육: 선임 후 **1년** 이내 |

### 면허 종별 개설 가능 의료기관

| 면허 | 개설 가능 기관 |
|---|---|
| **의사** | 종합병원, 병원, 요양병원, 정신병원, 의원 |
| **치과의사** | 치과병원, 치과의원 |
| **한의사** | 한방병원, 요양병원, 한의원 |
| **조산사** | 조산원 **만** |

> 2 이상 면허 소지자: **하나의 장소에 한하여** 면허 종별 의료기관 함께 개설 가능 (의원급만)

### 개설 금지 장소 (약국 분리 원칙)
1. 약국 시설 안이나 구내
2. 약국 시설/부지 분할·변경·개수하여 개설
3. 약국과 전용 복도·계단·승강기·구름다리 등 통로 연결
4. 무허가·무신고 건축물

### 의료기관 밖 진료 예외 (5가지)
1. **응급환자** 진료
2. **환자/보호자 요청**에 따른 진료
3. 국가/지자체장의 **공익상** 요청
4. **가정간호**
5. 부득이한 사유 (환자가 있는 현장)

### 부속 의료기관
- 개설 자격자 외의 자가 소속 직원 건강관리용으로 개설
- 의원급 → 시장·군수·구청장 **신고**
- 병원급 → 시·도지사 **허가** (원칙 동일)

### 수술실 CCTV
- 전신마취 수술 시 CCTV 촬영 원칙
- 영상 보관: **30일** 이상
- 녹음: 정보주체 **모두** 동의 시만 가능
- 촬영 거부 정당사유: 응급수술, 고위험 수술, 전공의 수련

### 시험장 판단 문장
- "의사 A가 의원 개설" → 시장·군수·구청장에게 **신고**
- "치과의사가 한방병원 개설?" → **불가**
- "약국 옆 전용 복도로 연결된 의원?" → **불가**

### 함정 패턴
1. 의원급인데 시·도지사 허가, 병원급인데 시군구청장 신고로 변조
2. 간호사·약사를 개설 가능자에 포함
3. 조산사가 병원 개설 가능하다고 변조
4. CCTV 보관기간 30일 → 60일/90일로 변조

## 3. 원격의료 [주체, 대상, 책임 분배]

### Switch Map

| 축 | 내용 |
|---|---|
| **원격지의사** | 의사·치과의사·한의사 **만** (간호사·조산사 X) |
| **대상** | 먼 곳에 있는 **의료인**에게 (의료인 → 의료인, 환자에게 직접 X) |
| **행위** | 정보통신기술로 의료지식·기술 지원 |
| **시설** | 원격진료실 + 데이터·화상 송수신 단말기/서버/정보통신망 |

### 책임 분배 구조 (핵심!)

```
원격지의사 ──(지식·기술 지원)──→ 현지의사
                                    │
                             환자에게 의료행위
```

| 현지의사 유형 | 책임 소재 |
|---|---|
| 현지의사가 **의사·치과의사·한의사** | 원격지의사 과실의 **명백한 근거** 없으면 → **현지의사** 책임 |
| 현지의사가 그 외 의료인 | **원격지의사** 책임 (직접 대면 진료와 동일 책임) |

### 시험장 판단 문장
- "원양어선에서 원격의료로 문제 발생, 책임?" → 현지의사가 의치한이면 **현지의사**, 아니면 **원격지의사**
- "간호사가 원격의료 가능?" → **불가**
- "의료인 → 환자 직접 원격진료?" → 현행법상 **불가** (의료인 → 의료인)

### 함정 패턴
1. 간호사·조산사도 원격의료 가능하다고 변조
2. 의료인 → 환자에게 직접 원격진료라고 변조
3. 현지의사가 의치한인데 무조건 원격지의사 책임이라고 변조
4. "명백한 근거" 조건을 빼먹기

## 4. 의료기관 폐업·휴업 [신고 대상, 기한, 진료기록부 이관]

### Switch Map

| 축 | 내용 |
|---|---|
| **신고 대상** | 개설 관청과 **무관하게** → 관할 **시장·군수·구청장** |
| **휴업 기준** | **1개월** 이상 (입원환자 있으면 1개월 미만도 포함) |
| **진료기록부** | 관할 **보건소장**에게 이관 (보건소장 허가 시 직접 보관 가능) |
| **사전안내** | 일반: **14일** 전 게시, 입원환자: **30일** 전 직접 안내 |

### 폐업 신고 수리 거부
- 감염병 역학조사 중 → 시군구청장이 **폐업 신고 수리 거부** 가능

### 의원급 개설 의료인 특례
- 부득이한 사유로 **6개월 초과** 관리 불가 시 → 폐업/휴업 신고 의무

### 시험장 판단 문장
- "병원급이 폐업 신고할 곳?" → 시·도지사가 **아니라** **시장·군수·구청장**
- "입원환자 있는 병원이 2주 휴업?" → **신고 필요** (입원환자 있으면 1개월 미만도)
- "폐업 시 진료기록부?" → **보건소장**에게 이관

### 함정 패턴
1. 병원급이니까 시·도지사에게 신고라고 변조 (모두 시장·군수·구청장)
2. 1개월 → 3개월로 변조
3. 입원환자 사전안내 30일 → 14일로 바꿈
4. 진료기록 이관 대상: 보건소장 → 보건복지부장관으로 변조
5. 입원환자 조건(1개월 미만 포함) 누락

## 5. 입원환자의 전원 [긴급 전원 요건, 승인 절차]

### Switch Map

| 축 | 내용 |
|---|---|
| **주체** | 의료기관의 장 |
| **승인** | **시장·군수·구청장** |
| **전제조건** | 천재지변·감염병·집단 사망사고 + 생명·건강 중대 위험 + 환자/보호자 동의 불가 |
| **통보** | 승인 여부: **지체 없이**; 보호자 안내: **지체 없이** (구두/유선/서면) |

### 긴급 전원 요건 3가지 (모두 충족)
1. 천재지변, 감염병 의심, 집단 사망사고 등 **긴급 상황**
2. 입원환자의 생명·건강에 **중대한 위험** 발생 가능
3. 환자 의사표시 불가 또는 보호자 연락 불가 → **동의 불가**

### 가명/전산관리번호 부여 환자
- 성명·주민번호 대신 가명/전산관리번호로 알림 가능
- 주소·전화번호 **생략 가능**

### 시험장 판단 문장
- "전원 승인 주체?" → **시장·군수·구청장** (시·도지사 아님, 보건복지부장관 아님)
- "전원 후 보호자 통보 기한?" → **지체 없이** (7일, 14일 아님)

### 함정 패턴
1. 승인 주체를 시·도지사/보건복지부장관으로 변조
2. 동의 가능한데도 승인만으로 전원 가능하다고 변조
3. "지체 없이" → "7일 이내"로 변조

## 6. 의료광고 [금지 유형, 심의, 매체 제한]

### Switch Map

| 축 | 내용 |
|---|---|
| **주체** | **의료인등**만 (개설자, 의료기관장, 의료인) |
| **심의** | 자율심의기구 (의사회·치과의사회·한의사회 또는 소비자단체) |
| **유효기간** | **3년** (만료 **6개월** 전 재심의) |
| **처분 통보** | 위반 시 **공정거래위원회**에 통보 |

### 의료광고 15개 금지 유형 (핵심 항목)

| 번호 | 유형 | 키워드 |
|---|---|---|
| 1 | 신의료기술 미평가 광고 | 평가 안 받은 기술 |
| 2 | **치료경험담** | 치료 효과 오인 |
| 3 | 거짓 내용 | 허위사실 |
| 4 | **비교광고** | 다른 의료인 기능 비교 |
| 5 | 비방광고 | 다른 의료인 비방 |
| 6 | **수술장면 노출** | 시술행위 직접 노출 |

## 8. 개설 허가 취소 등 [9가지 사유, 필요적 vs 임의적, 재개설 제한]

### Switch Map

| 축 | 내용 |
|---|---|
| **주체** | **보건복지부장관** 또는 **시장·군수·구청장** |
| **처분** | **1년** 범위 의료업 정지 / 개설허가 취소 / 폐쇄 |
| **폐쇄 대상** | **신고한** 의료기관에만 가능 |
| **재개설 금지** | 일반: **6개월**, 제8호: **3년**, 정지: 정지기간 중 |

### 9가지 처분 사유

| 호 | 사유 | 처분 유형 |
|---|---|---|
| 1 | 허가/신고 후 **3개월 이내 미개업** | 임의적 |
| 1의2 | 타인 명의 개설·운영 | 임의적 |
| 2 | **무자격자에게 의료행위** 시킴 | 임의적 |
| 3 | 관계 공무원 직무수행 기피·방해, 명령 위반 | 임의적 |
| 4 | 법인 설립허가 취소·해산 | 임의적 |
| 4의2 | 개설 자격 위반 (제33조 제2항) | 임의적 |
| 4의3 | **2개소 이상 개설·운영** | 임의적 |
| 5 | 각종 위반 (제33조 제5,7,9,10항, 제40조, 제56조) | 임의적 |
| 5의2 | 무신고 **6개월 이상 미영업** | 임의적 |
| 6 | **시정명령 불이행** (제4조 제5항 위반 제외) | 임의적 |
| 7 | 약사법 담합행위 | 임의적 |
| **8** | **거짓 진료비 청구 → 금고 이상 형 확정** | **필요적** |
| 9 | 준수사항 위반 → 생명·신체 중대 위해 | 임의적 |

### 필요적 처분 vs 임의적 처분

| 구분 | 필요적 (제8호) | 임의적 (나머지) |
|---|---|---|
| 내용 | 거짓 진료비 청구 + 금고 이상 확정 | 위 표 참조 |
| 처분 | **반드시** 허가 취소 또는 폐쇄 | 정지/취소/폐쇄 **선택** |
| 정지 가능? | **불가** (정지는 안 됨) | 가능 (1년 범위) |
| 재개설 금지 | **3년** | **6개월** |

### 시험장 판단 문장
- "거짓 진료비 → 금고 이상 확정 → 처분?" → **반드시 취소 또는 폐쇄** + 3년 재개설 금지
- "허가 후 2개월 미개업 → 처분 가능?" → **아직 불가** (3개월이 안 됨)
- "취소 후 재개설 가능 시점?" → 일반: **6개월** 후, 제8호: **3년** 후
- "폐쇄 가능 대상?" → **신고한** 의료기관에만 (허가 받은 기관은 취소만 가능)

### 함정 패턴
1. 재개설 금지 6개월 → 1년; 제8호 3년 → 5년
2. 미개업 3개월 → 6개월로 변조
3. 제8호인데 정지도 가능하다고 변조 (불가)
4. 일반 사유인데 반드시 취소라고 변조
5. 시·도지사가 처분 주체라고 변조
6. 정지 범위 1년 → 2년 또는 6개월
