## 1. 의료인의 정의

### Switch Map

| 축 | 답 |
|---|---|
| 누가 | 보건복지부장관 (면허 발급) |
| 대상 | 의사·치과의사·한의사·조산사·간호사 |
| 무엇을 | 종별 임무 수행 |
| 기한 | 해당 없음 |
| 예외 | 해당 없음 |
| 처분 | 면허 외 의료행위 → 무면허 의료행위 위반 |

### 종별 임무 정리

| 종별 | 임무 |
|---|---|
| 의사 | 의료 + 보건지도 |
| 치과의사 | 치과 의료 + 구강 보건지도 |
| 한의사 | 한방 의료 + 한방 보건지도 |
| 조산사 | 조산 + 임산부·신생아 보건·양호지도 |
| 간호사 | (1) 간호판단·요양간호 (2) 의·치·한 지도하 진료보조 (3) 교육·상담·보건활동 (4) 간호조무사 업무보조 지도 |

### 시험장 판단 문장
> "의료인은 의·치·한·조·간 5종뿐이며, 약사·의료기사·간호조무사는 의료인이 아니다."

### 함정 패턴
- 약사, 의료기사, 간호조무사를 의료인에 포함 → X
- 간호사에 "독자적 처방/진단" 포함 → X (의·치·한 지도하 진료보조)
- 조산사 임무에 "간호" 포함 → X (조산 + 임산부/신생아 보건·양호지도)
- 면허 발급 주체를 "시·도지사"로 변경 → X (보건복지부장관)

## 2. 면허증 발급과 재발급

### Switch Map

| 축 | 답 |
|---|---|
| 누가 | 보건복지부장관 (면허 발급·국시 시행) |
| 대상 | 평가인증기구 인증 대학 졸업자, 외국 면허 소지자(예비시험 합격 필요) |
| 무엇을 | 국시 합격 후 면허 발급, 면허 조건 부과, 면허증 재발급 |
| 기한 | 졸업예정자: **6개월** 이내 / 면허 조건: **3년** 이내 / 부정행위 제한: **3회** 범위 / 재발급 사진: 신청 전 **6개월** 이내 촬영 |
| 예외 | 입학 당시 인증 대학이면 졸업 시 인증 상태 무관 / 외국 면허자는 예비시험 필요 |
| 처분 | 부정행위 → 수험 정지/합격 무효 + 차기 3회 제한 / 면허 조건 불이행 → 면허 취소(재교부 1년 이내 불가) |

### 면허 취득 경로

```
평가인증기구 인증 대학 졸업 (또는 6개월 이내 졸업 예정)
    ↓
국가시험 합격 (관리: 한국보건의료인국가시험원)
    ↓
보건복지부장관 면허 발급
```

### 면허증 재발급 경로

| 구분 | 경로 |
|---|---|
| 분실/훼손 | 보건복지부장관에게 **직접** 제출 |
| 취소된 면허 재발급 | **시·도지사를 거쳐** 보건복지부장관에게 제출 |

### 시험장 판단 문장
> "졸업예정 6개월, 면허조건 3년, 부정행위 3회 — 숫자 바꿔치기를 경계하라."

### 함정 패턴
- 졸업예정 "1년 이내" → X (6개월)
- 면허 조건 "5년" → X (3년)
- 부정행위 제한 "5회" → X (3회)
- 국시 관리를 "대한의사협회" → X (한국보건의료인국가시험원)
- 취소 면허 재발급을 "보건복지부장관에게 직접" → X (시·도지사 경유)

## 3. 의료인의 결격사유

### Switch Map

| 축 | 답 |
|---|---|
| 누가 | 보건복지부장관 (면허 취소 의무) |
| 대상 | 결격사유 해당 의료인 |
| 무엇을 | 의료인이 될 수 없음 → 면허 **필수** 취소 |
| 기한 | 실형: 집행 종료/면제 후 **5년** / 집행유예: 유예기간 경과 후 **2년** / 선고유예: **유예기간 중** |
| 예외 | 정신질환자: **전문의**가 적합하다고 인정하면 결격 아님 |
| 처분 | 면허 필수 취소 + 국시 응시 불가 |

### 결격사유 6가지

| 번호 | 사유 | 기간 |
|---|---|---|
| 1 | 정신질환자 | - (전문의 인정 시 예외) |
| 2 | 마약·대마·향정신성의약품 중독자 | - |
| 3 | 피성년후견인·피한정후견인 | - |
| 4 | 금고 이상 **실형** | 집행 종료/면제 후 **5년** |
| 5 | 금고 이상 **집행유예** | 유예기간 경과 후 **2년** |
| 6 | 금고 이상 **선고유예** | **유예기간 중** |

### 시험장 판단 문장
> "결격 = 필수취소. 실형 5년, 집유 2년, 선유 기간중. 벌금형은 결격 아님."

### 함정 패턴
- 실형 후 "3년" → X (5년)
- 집행유예 후 "5년" → X (2년)
- 선고유예를 "유예기간 경과 후 2년" → X (유예기간 **중**)
- "벌금형"을 결격사유에 포함 → X (금고 이상만)
- 정신질환자 단서를 "보건복지부장관이 인정" → X (전문의가 인정)

## 4. 의료인의 권리

### Switch Map

| 축 | 답 |
|---|---|
| 누가 | 의료인 (권리 주체) / 누구든지 (금지 의무) |
| 무엇을 | (1) 의료행위 간섭 금지 (2) 의료기재 압류 금지 (3) 기구 등 우선공급 |
| 예외 | 간섭 금지: 법령에 따로 규정된 경우는 가능 |
| 처분 | 시설 파괴·점거·폭행·협박 → 형사처벌 |

### 의료인 3대 권리

| 조문 | 권리 | 내용 |
|---|---|---|
| 제12조 | 의료행위 간섭 금지 | 누구든지 의료행위에 간섭 못함 |
| 제13조 | 의료기재 압류 금지 | 의료업무에 필요한 기구·약품 압류 불가 |
| 제14조 | 기구 등 우선공급 | 기구·약품·시설·재료 + 부수 물품·노력·교통수단 |

### 의료기관 보호 (제12조②③)
- 시설·기재·약품 **파괴·손상** 금지
- 의료기관 **점거**하여 진료 방해 금지
- 의료행위 장소에서 **폭행·협박** 금지 (대상: 의료인, 간호조무사, 의료기사, 환자)

### 시험장 판단 문장
> "의료인 권리 3가지 = 간섭 금지, 압류 금지, 우선공급. 진료거부 금지는 '의무'이다."

### 함정 패턴
- 의료기재 "압류 가능" → X
- 우선공급에서 "교통수단" 제외 → X (포함)
- "진료거부 금지"를 권리로 분류 → X (의무)

## 5. 의료인의 의무

### Switch Map

| 축 | 답 |
|---|---|
| 누가 | 의료인, 의료기관의 장, 의료기관 개설자 |
| 대상 | 환자·보호자 (설명·동의) / 보건복지부장관 (실태신고) / 경찰서장 (변사체 신고) |
| 주요 의무 | 진료거부 금지, 면허대여 금지, 일회용 재사용 금지, 정보누설 금지, 태아 성감별 금지, 수술 등 설명·동의, 실태신고, 변사체 신고 |
| 기한 | 실태신고: **3년마다** (12월 31일까지) / 세탁물처리업자 휴업: **1개월 이상** 시 신고 |
| 예외 | 설명·동의 면제: 생명 위험·심신상 중대 장애 우려 시 / 태아 성감별: 목적 검사만 금지(성별 고지 시기 제한 없음, 위헌 삭제) |

### 수술 등 설명·동의 (제24조의2) — 법정 설명사항 5가지

| 번호 | 설명사항 |
|---|---|
| 1 | 환자에게 발생하거나 발생 가능한 **진단명** |
| 2 | 수술등의 **필요성·방법·내용** |
| 3 | 설명하는 의사 및 참여하는 의사의 **성명** |
| 4 | 수술등에 따라 전형적으로 발생이 예상되는 **후유증·부작용** |
| 5 | 수술 전후 환자가 준수해야 할 **사항** |

> **주의**: "비용"은 법정 설명사항이 아님!
> 설명·동의 주체: 의사·치과의사·한의사만 (간호사 X)
> 응급 예외: 생명 위험 또는 심신상 중대한 장애 우려 → 면제

### 실태·취업상황 신고 (제25조)
- 주기: 최초 면허 후 **3년마다**
- 기한: 해당 해 **12월 31일**까지
- 대상: **보건복지부장관**에게 신고

### 변사체 신고 (제26조)
- 신고 대상: 사체 소재지 관할 **경찰서장**
- "보건복지부장관" 또는 "시·도지사" → X

### 태아 성 감별 행위 금지 (제20조)
- 성감별 **목적** 진찰·검사만 금지
- 산전진찰 중 알게 된 성별 고지: **시기 제한 없음** (임신 32주 조항은 위헌으로 삭제)

### 시험장 판단 문장
> "실태신고 3년마다, 변사체는 경찰서장, 설명사항에 비용은 없다."

### 함정 패턴
- 실태신고 "5년마다" → X (3년마다)
- 변사체 신고를 "보건복지부장관/시·도지사" → X (경찰서장)
- 설명사항에 "비용" 포함 → X
- 설명·동의 주체에 "간호사" 포함 → X
- "임신 32주 이전 성별 고지 금지" → X (위헌 삭제)

## 6. 진단서

### Switch Map

| 축 | 답 |
|---|---|
| 누가 | 진단서/검안서/증명서: **의사·치과의사·한의사** / 출생·사망·사산 증명서: **의사·한의사·조산사** |
| 대상 | 환자 본인 / 사망·의식불명 시: 직계존비속, 배우자, 배우자 직계존속 → 모두 없으면 형제자매 |
| 기한 | 최종 진료 후 **48시간** 이내 사망 → 재진 없이 발급 가능 / 진단서 부본 보존: **3년** |
| 예외 | 부득이시 **같은 의료기관** 다른 의사가 진료기록부에 따라 발급 가능 |

### 발급 주체 비교

| 서류 | 발급 주체 |
|---|---|
| 진단서·검안서·증명서 | 의사, 치과의사, 한의사 |
| 출생·사망·사산 증명서 | 의사, 한의사, **조산사** (치과의사 X) |

### 상해진단서 추가 기재사항
1. 상해 원인, 부위·정도, 소견
2. "여부" 항목: 입원 필요 여부, 수술 여부, 합병증 발생 가능 여부, 통상 활동 가능 여부, 식사 가능 여부
3. 치료기간

### 시험장 판단 문장
> "진단서는 의·치·한, 출생/사망/사산은 의·한·조. 48시간 이내 사망이면 재진 불요."

### 함정 패턴
- 48시간을 "24시간/72시간" → X
- 출생/사망/사산 증명서에 "치과의사" 포함 → X
- 형제자매를 무조건 포함 → X (다른 친족이 모두 없는 경우만)
- 대리 발급을 "다른 의료기관 의사" → X (같은 의료기관)

## 7. 처방전

### Switch Map

| 축 | 답 |
|---|---|
| 누가 | 처방전 작성·교부: **의사·치과의사** (제18조) / 처방전 교부: **의사·치과의사·한의사** (제17조의2) |
| 대상 | 환자 본인 / 대리수령자: 직계존비속, 배우자, 배우자 직계존속, 형제자매, 노인의료복지시설 근무자 |
| 무엇을 | 처방전 2부 작성·교부, 약사 문의 즉시 응답, 의약품정보 사전 확인 |
| 기한 | 처방전 보존: **2년** / 대리수령 신청서 보관: **1년** |
| 예외 | 대리수령: (1) 환자 의식 없음 (2) 거동곤란 + 장기간 동일처방 / 약사 문의 응답 예외: 응급진료, 수술·처치 중 |

### 대리수령 조건

| 조건 | 내용 |
|---|---|
| 조건 1 | 환자의 **의식이 없는** 경우 |
| 조건 2 | 거동이 현저히 곤란 **+** 동일 상병에 장기간 **동일 처방** |

> **주의**: 조건 2는 두 가지 모두 충족해야 함!

### 대리수령 필요 서류
1. 대리수령 **신청서**
2. 대리수령자 **신분증**
