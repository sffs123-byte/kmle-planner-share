# Core 7 — 마약류관리법 복습 노트
> 문제 50개 | 이론 5개 (정의 / 취급자 / 관리 / 저장 / 중독자)

---

## 핵심 축 정리

마약류관리법의 시험 출제 축은 크게 4가지이다.

1. **3분류 구분**: 마약 vs 향정신성의약품 vs 대마 — 정의·제외 대상·저장 기준이 전부 다르다
2. **누가 허가/지정하는가**: 식약처장 vs 시군구청장 — 취급자 9종의 허가/지정 권한자
3. **보고/승인 경로**: 취급 보고(식약처장) vs 사고 보고(허가관청) vs 양도 승인(식약처장)
4. **숫자 함정**: 사고보고 5일, 처방전 보존 2년, 판별검사 1개월, 치료보호 12개월, 재지정 3년

## 1. 정의 [마약/향정/대마 구분]

### 마약류 = 마약 + 향정신성의약품 + 대마 (제2조)

### 1-1. 마약
| 분류 | 내용 | 비고 |
|------|------|------|
| 가 | **양귀비** (파파베르 솜니페룸 등) | |
| 나 | **아편** (양귀비 액즙 응결물 + 가공물) | **의약품으로 가공한 것 = 제외** |
| 다 | **코카 잎** | 엑고닌·코카인·엑고닌 알칼로이드 **모두** 제거된 잎 = 제외 |
| 라 | 양귀비/아편/코카 잎에서 추출된 알칼로이드 + 동일 화학적 합성품 | 코카인, 모르핀, 옥시코돈, 헤로인, 코데인 등 (**대통령령**) |
| 마 | 가~라 외 동일하게 남용/해독 우려 화학적 합성품 | 메타돈, 페티딘 등 (**대통령령**) |
| 바 | 가~마 함유 혼합물질/혼합제제 | **한외마약 = 제외** |

> **한외마약**: 다른 약물과 혼합되어 재제조 불가 + 의존성 없는 것 → **총리령**으로 정함 → **마약이 아니다**

### 1-2. 향정신성의약품 (가~마목)
| 목 | 남용 우려 | 의료용 | 의존성 |
|----|-----------|--------|--------|
| **가** | 심함 | **쓰이지 않음** + 안전성 결여 | 심한 신체적 + 정신적 |
| **나** | 심함 | **매우 제한된** 의료용 | 심한 신체적 + 정신적 |
| **다** | 상대적으로 적음 | 의료용 | 그리 심하지 않은 신체적 **또는** 심한 정신적 |
| **라** | 다목보다 적음 | 의료용 | 다목보다 낮은 의존성 |
| **마** | 가~라 혼합물질/혼합제제 | — | 재제조 불가 + 의존성 없으면 **총리령**으로 제외 |

> **대통령령**으로 구체 약물 지정. 암페타민, 메틸페니데이트, 페노바비탈, **프로포폴**, 벤조디아제핀계 등

### 1-3. 대마 (제2조 제4호)
- 대마초와 그 수지
- 대마초/수지 원료 제조 모든 제품
- 동일 화학적 합성품 (대통령령)
- 위 함유 혼합물질/혼합제제

> **제외**: 대마초의 **종자** · **뿌리** · **성숙한 줄기**와 그 제품

### 1-4. 기타 정의
| 용어 | 정의 |
|------|------|
| 원료물질 | 마약류가 아닌 물질 중 마약/향정 제조에 사용되는 물질 (대통령령) |
| 군수용마약류 | 국방부·직할기관·육해공군이 관리하는 마약류 |
| 치료보호 | 마약류 중독자의 의존성 극복 + 재발 예방 → 입원/통원 치료 |
| **임시마약류** | **식품의약품안전처장**이 긴급히 마약류에 준하여 관리 필요 시 지정 |

## 2. 마약류취급자 [9종]

| 구분 | 취급자 | 업무 | 허가/지정 |
|------|--------|------|-----------|
| 가 | **마약류수출입업자** | 마약/향정 수출입 | **식약처장** 허가 |

### 2-2. 마약류관리자 의무 설치

- **마약류취급의료업자 4명 이상** 의료기관 → 마약류관리자(약사) **의무** 지정
- **향정신성의약품만** 취급하는 의료기관 → 마약류관리자 **불요**
- 지정 권한: **시군구청장** (2023.06.11 개정, 구 시도지사)

## 3. 마약류의 관리

### 3-1. 수수 제한 (제9조)
- 마약류취급자/취급승인자 **상호 간에만** 양수·양도 가능
- 양수 제한 예외: 자격 상실자로부터 **허가관청 승인** 시 (제13조)

### 3-2. 양도 제한 및 예외 (제9조 제2항)
| 양도 가능 예외 | 승인 주체 |
|---------------|-----------|
| 품목허가 취소로 양도 | **식약처장** 승인 |
| 학술연구자·취급승인자에게 양도 | **식약처장** 승인 |
| 반품 | 승인 불요 |
| 희귀의약품센터 → 취급승인자 양도 | 승인 불요 |

- 제조업자·원료사용자·학술연구자 간 양도 → **식약처장 승인** 필요

### 3-3. 취급 보고 (제11조)
- **보고 대상**: **식품의약품안전처장**
- 보고 내용: 품명·수량·취급연월일·구입처·재고량·일련번호·상대방 성명
- 의료업자·소매업자 추가 보고: 환자 주민등록번호, 질병분류기호
- **마약류관리자 있는 의료기관** → 관리자가 **보고 대행**

### 3-4. 사고 마약류 보고 (제12조) — **최빈출**

| 항목 | 내용 |
|------|------|
| **보고 대상** | **허가관청** (의료업자=개설허가·신고관청, 소매업자=약국등록관청) |
| **보고 기한** | 사유 발생을 안 날부터 **5일 이내** |
| **사고 사유** | (1) 재해 상실 (2) 분실·도난 (3) 변질·부패·파손 |

**증명서류 발급기관** (시험 핵심):

| 사고 유형 | 증명서류 발급기관 |
|-----------|------------------|
| **재해** | **시·도지사** |
| **분실·도난** | **수사기관** |
| 변질·부패·파손 | 증명서류 **불요** |

### 3-5. 폐기 (제12조 제2항)
- 변질·부패·파손, 유효기한 경과, 재고관리 곤란 시
- **관계공무원 참관** 하에 폐기

### 3-6. 처방전 (제32조)
- 마약류취급의료업자가 마약/향정 처방전 발급
- **처방전·진료기록부 보존기간**: **2년**
- **처방전 없이 투약 가능**: 직접 조제 가능한 의사(진료기록부 기재), 수의사(진료부 기재)

### 3-7. 광고 (제14조)
- 마약류제조업자·수출입업자만 광고 가능
- **전문 매체**에 한정 (의학·약학·수의학 전문 신문/잡지, 제품설명회)

## 4. 마약류의 저장

### 4-1. 저장 기준 3분류 비교 — **반드시 암기**

| 구분 | 마약 | 향정신성의약품 | 대마 |
|------|------|---------------|------|
| **저장 기준** | **이중잠금장치** 철제금고 | **잠금장치** 설치 장소 | **잠금장치** + **출입 제한** |
| **조제대 비치** | **불가** | 업무시간 중 가능 (소매업자·의료업자·관리자) | **불가** |

### 4-2. 공통 저장 원칙
- 업소·사무소 **안**에 설치
- 일반인이 **쉽게 발견할 수 없는** 장소
- **이동 불가**하도록 설치
- 다른 의약품과 **구별** 저장

### 4-3. 봉함 (제16조)
- **봉함 의무자**: 수출입업자, 제조업자, 원료사용자, 학술연구자, 취급승인자
- 봉함 기준: 뜯지 않고는 개봉 불가 + 개봉 후 원상 회복 불가
- **봉함 없이 수수 가능 예외**: 반품 시, 자격상실자 양도 시 식약처장 승인

### 4-4. 용기 표시 (제17조)
- 마약·향정·한외마약의 용기·포장·첨부문서에 총리령 사항 기재
- **붉은색**으로 **"마약"** 또는 **"향정신성"** 문자 표시
- 다른 문자·그림보다 **쉽게 볼 수 있는 부분**에 표시

## 5. 마약류 중독자

### 5-1. 마약 사용 금지 (제39조)
- **주체**: 마약류취급의료업자
- **대상**: **마약** 중독자에게 **마약** 투약·제공·처방전 발급 **금지**
- 주의: "마약류" 전체가 아니라 **"마약"** 중독자에게 **"마약"**만 금지

### 예외
- **치료보호기관**에서 **보건복지부장관 또는 시·도지사**의 허가를 받은 경우

### 5-2. 치료보호 (제40조)

| 항목 | 내용 |
|------|------|
| **설치·지정 주체** | 보건복지부장관 또는 시·도지사 |
| **시도지사 지정 시** | 복지부장관에게 **통보** |
| **판별검사 기간** | **1개월** 이내 |
| **치료보호 기간** | **12개월** 이내 |
| **재지정 평가** | **3년**마다 |
| **심의** | **치료보호심사위원회** 심의 필수 |
| **비용** | 국가·지자체 부담 |

### 5-3. 치료보호기관 필수 인력·시설
- 소변·모발 등 생체시료 분석 기기·장비
- **정신건강의학과 전문의**
- **정신건강전문요원**
- 보조적 검사장비

### 5-4. 치료보호심사위원회
| 위원회 | 소속 | 심의 사항 |
|--------|------|-----------|
| **중앙**치료보호심사위원회 | 보건복지부 | 기본방향, 판별검사 기준, 복지부장관 지정 기관 치료보호 |
| **지방**치료보호심사위원회 | 시·도 | 시도지사 지정 기관 치료보호 |

### 5-5. 치료보호기관 지정 취소
| 취소 유형 | 사유 |
|-----------|------|
| **필수** 취소 | 거짓·부정 방법으로 지정받은 경우 |
| **임의** 취소 | 취소 요청, 평가 결과 시설·인력 미비 |

## Cross-cutting 비교표

### 마약 vs 향정 vs 대마 종합 비교

| 비교 항목 | 마약 | 향정신성의약품 | 대마 |
|-----------|------|---------------|------|
| **정의 근거** | 제2조 제2호 | 제2조 제3호 | 제2조 제4호 |
| **세부 분류** | 양귀비·아편·코카 잎·알칼로이드·합성품·혼합제제 | 가~마목 (남용 정도·의료용 여부) | 대마초+수지·제품·합성품·혼합제제 |
| **제외 대상** | 한외마약(총리령), 아편 의약품 가공물, 코카 잎(성분 제거) | 마목 중 의존성 없는 혼합물(총리령) | 종자, 뿌리, 성숙한 줄기와 그 제품 |
