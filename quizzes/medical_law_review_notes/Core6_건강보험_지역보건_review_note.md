## 핵심 축 정리

| 축 | 국민건강보험법 | 지역보건법 |
|---|---|---|
| **핵심 기관** | 공단(NHIS) · 심평원(HIRA) | 보건소 · 보건의료원 · 보건지소 · 건강생활지원센터 |

## Part A: 국민건강보험법 (24Q)

### 1. 공단 · 심평원 역할 구분

#### 국민건강보험공단 (NHIS) — 법 제13조, 제14조

건강보험의 **보험자** = 공단

| # | 공단 업무 (제14조 제1항, 13개) |
|---|---|
| 1 | 가입자 · 피부양자의 **자격 관리** |
| 2 | 보험료 및 징수금의 **부과 · 징수** |
| 3 | **보험급여의 관리** |
| 4 | 요양급여 실시현황 · 건강검진 결과 활용 **예방사업** |
| 5 | 보험급여 비용의 **지급** |
| 6 | 자산의 관리 · 운영 · 증식사업 |
| 7 | 의료시설의 운영 |
| 8 | 건강보험에 관한 교육훈련 · 홍보 |
| 9 | 건강보험에 관한 조사연구 · 국제협력 |
| 10 | 법에서 공단 업무로 정한 사항 |
| 11 | 국민연금법 · 고용보험 등 위탁받은 업무 |
| 12 | 다른 법령에 따라 위탁받은 업무 |
| 13 | 보건복지부장관이 필요하다고 인정한 업무 |

> **외우기 핵심**: "자격 · 보험료 · 급여비용 **지급** → 공단"

#### 건강보험심사평가원 (HIRA) — 법 제62조, 제63조

| # | 심평원 업무 (제63조 제1항, 8개) |
|---|---|
| 1 | 요양급여비용의 **심사** |
| 2 | 요양급여의 **적정성 평가** |
| 3 | 심사기준 · 평가기준의 **개발** |
| 4 | 위 업무 관련 조사연구 · 국제협력 |
| 5 | 다른 법률에 따른 급여비용 심사 · 적정성 평가 **위탁** |
| 6 | 다른 법령에 따라 위탁받은 업무 |
| 7 | 보건복지부장관이 필요하다고 인정한 업무 |
| 8 | 대통령령으로 정하는 업무 |

> **외우기 핵심**: "**심사** · **평가** → 심평원"
> 적정성 평가 기준·절차·방법 **고시** → **보건복지부장관** (심평원장이 아님!)

#### 초빈출 주체 교환 함정

| 행위 | 정답 주체 | 오답 유도 |
|---|---|---|
| 급여비용 **지급** | 공단 | 심평원 |
| 급여비용 **심사** | 심평원 | 공단 |
| 적정성 **평가** | 심평원 | 공단 |
| 보험급여 **관리** | 공단 | 심평원 |
| 적정성 평가 기준 **고시** | 보건복지부장관 | 심평원장 |

### 2. 보험급여 5종 · 요양급여 7개 항목

#### 보험급여 5종

| 종류 | 내용 | 비고 |
|---|---|---|
| **① 요양급여** | 7개 항목 (아래) | 요양기관에서 실시 |
| **② 요양비** | 복막투석·산소치료·혈당검사/인슐린·자가도뇨·인공호흡기/기침유발기·양압기·출산 | **공단**에 청구 |
| **③ 부가급여** | 임신출산 진료비(이용권) | 현재 유일하게 시행 중 |
| **④ 장애인보조기기** | 보장구 급여 | |
| **⑤ 건강검진** | 일반/암/영유아 | 일반: 직장가입자 + 20세 이상 지역가입자·피부양자; 영유아: **6세 미만** |

> **함정**: 장제비를 급여 종류에 넣으면 오답. 건강검진을 부가급여에 넣으면 오답.
> 영유아건강검진: **6세 미만** (7세·5세 아님)

#### 요양급여 7개 항목 (법 제41조 제1항)

1. 진찰 · 검사
2. 약제 · 치료재료의 지급
3. 처치 · 수술 및 그 밖의 치료
4. 예방 · 재활
5. 입원
6. **간호**
7. **이송**

> **간호 · 이송**: 요양급여 항목이지만 **요양기관에서의 실시 대상에서 제외** (법 제42조 "간호와 이송은 제외한다")

#### 요양기관 범위 (법 제42조)

| # | 요양기관 |
|---|---|
| 1 | 의료법에 따른 **의료기관** |
| 2 | 약사법에 따른 **약국** |
| 3 | **한국희귀·필수의약품센터** |
| 4 | 지역보건법에 따른 **보건소·보건의료원·보건지소** |
| 5 | 농어촌의료법에 따른 **보건진료소** |

- 요양기관은 정당한 이유 없이 요양급여 **거부 불가**
- **전문요양기관**: 보건복지부장관이 인정 → 인정서 발급 → 기준 미달 또는 인정서 반납 시 인정 **취소**

#### 요양급여비용 계약 (법 제45조)

| 항목 | 내용 |
|---|---|
| 계약 당사자 | **공단 이사장** + **의약계 대표** |
| 계약 기한 | 직전 계약 만료연도 **5월 31일**까지 |
| 미체결 시 | **6월 30일**까지 보건복지부장관이 **건강보험정책심의위원회** 의결 거쳐 결정 |

> **함정**: 5/31과 6/30을 바꾸면 오답

#### 요양기관 현황 신고 (법 제43조)

- 최초 청구 시 → **심평원**에 신고
- 변경 시 → 변경일부터 **15일 이내** 심평원에 신고 (30일 아님!)

#### 선별급여 · 방문요양급여 · 비급여

| 구분 | 핵심 |
|---|---|
| **선별급여** | 경제성·치료효과 불확실 → 본인부담 **상향** 가능 |
| **비급여** | 업무·일상생활 지장 없는 질환 치료 등 → 보건복지부장관 결정 |
| **방문요양급여** | 거동 불편(중증장애·말기환자·18세 미만 인공호흡기 등) → 직접 방문하여 요양급여 실시 |
| **본인부담상한액** | 연간 기준, 초과분은 **공단** 부담 |

### 3. 이의신청 · 심판청구 — 3단계 불복 절차

```
이의신청 → 심판청구 → 행정소송
```

#### 이의신청 (법 제87조)

| 처분 기관 | 이의신청 대상 | 신청처 |
|---|---|---|
| **공단** 처분 | 자격·보험료·보험급여·급여비용 | **공단**에 이의신청 |
| **심평원** 처분 | 요양급여비용·적정성 평가 | **심평원**에 이의신청 |

> **기억법**: "환자는 공단에, 의사는 심평원에"

**이의신청 기한**:
- 처분을 **안 날부터 90일** 이내
- 처분이 **있은 날부터 180일** 경과 시 제기 불가
- **예외**: 심평원의 확인(제48조)에 대한 이의신청 → 통보받은 날부터 **30일** 이내
- 정당한 사유 소명 시 기간 도과 허용

#### 심판청구 (법 제88조)

- 이의신청 결정에 **불복**하는 자
- **건강보험분쟁조정위원회** (보건복지부 산하)에 심판청구
- 기한: 이의신청과 동일 (90일/180일) 준용
- 심판청구서 제출처: 처분 기관(공단/심평원) 또는 분쟁조정위원회

#### 건강보험분쟁조정위원회 (법 제89조)

| 항목 | 내용 |
|---|---|
| 소속 | **보건복지부** (공단 산하 아님!) |
| 위원 수 | 위원장 포함 **60명 이내** |
| 비공무원 비율 | 전체 위원의 **과반수** |
| 회의 구성 | 위원장 + 당연직위원 + 지정 7명 = 총 **9명** |
| 회의 비공무원 | 9명 중 **과반수** |
| 의결 | 구성원 과반수 출석 + 출석위원 과반수 찬성 |
| 비공무원 위원 | 형법상 뇌물죄 적용 시 **공무원으로 간주** |

#### 행정소송 (법 제90조)

- 공단/심평원 처분에 이의 있는 자 또는 이의신청·심판청구 결정에 불복하는 자
- **이의신청·심판청구 거치지 않고도 직접 제기 가능**

### 4. 자격 상실 · 급여 정지

#### 자격 상실 사유 · 시점 (법 제10조)

| # | 사유 | 상실 시점 | 구분 |
|---|---|---|---|
| 1 | **사망** | 사망한 날의 **다음 날** | 다음 날 |
| 2 | **국적 상실** | 국적을 잃은 날의 **다음 날** | 다음 날 |
| 3 | **국내 미거주** | 국내에 거주하지 아니하게 된 날의 **다음 날** | 다음 날 |
| 4 | 직장가입자의 **피부양자** 전환 | 피부양자가 **된 날** | 된 날 |
| 5 | **수급권자** 전환 | 수급권자가 **된 날** | 된 날 |
| 6 | 유공자등 의료보호대상자 → **적용배제 신청** | 적용배제 **신청한 날** | 신청한 날 |

> **"다음 날" 3가지**: 사망 · 국적상실 · 국내 미거주
> **"된 날" 2가지**: 피부양자 · 수급권자
> **"신청한 날"**: 유공자 적용배제

- **자격상실 신고 기한**: 자격을 잃은 날부터 **14일** 이내 → 보험자(공단)에게
- 신고 의무자: 직장가입자의 **사용자** / 지역가입자의 **세대주**

#### 급여 정지 사유 (법 제54조)

| # | 정지 사유 | 예탁 지급 |
|---|---|---|
| (삭제) | — | — |
| 2 | **국외 체류** | **불가** (완전 정지) |
| 3 | 현역병 · 전환복무 · **군간부후보생** | **가능** (법 제60조) |
| 4 | 교도소 등 **수용** | **가능** (법 제60조) |

#### 현역병 등에 대한 예탁 지급 (법 제60조)

- **공단**이 요양급여비용 + 요양비를 지급
- 예탁 주체: **법무부장관·국방부장관·경찰청장·소방청장·해양경찰청장**
- 예산상 불가피한 경우 외에는 연간 예상 비용을 미리 공단에 **예탁**

> **함정**: 공보의·군의관은 현역병이 아니므로 급여정지 대상 아님
> **함정**: 국외체류자는 예탁 지급 대상이 아님 (완전 정지)

## Part B: 지역보건법 (27Q)

### 1. 지역사회 건강실태조사 · 지역보건의료계획

#### 지역사회 건강실태조사 (법 제4조, 시행령 제2조)

| 항목 | 내용 |
|---|---|
| 실시 주체 | **질병관리청장** + **시장·군수·구청장** |
| 실시 주기 | **매년** |
| 조사 방법 | **표본조사** 원칙 (필요 시 전수조사 가능) |
| 사전 절차 | 질병관리청장이 **보건복지부장관과 협의** |
| 조사 실행 | 질병관리청장 → 지자체장에게 협조 요청 → 지자체장이 **보건소를 통해** 주민 대상 조사 |
| 결과 보고 | 지자체장 → **질병관리청장**에게 통보 |

**조사 내용** (시행령 제2조 제4항):
1. 흡연·음주 등 **건강 관련 생활습관**
2. 건강검진·예방접종 등 **질병 예방**
3. 질병 및 **보건의료서비스 이용 실태**
4. **사고 및 중독**
5. **활동 제한 및 삶의 질**
6. 질병관리청장이 정하는 기타 사항

> **함정**: 보건복지부장관이 실시한다 → 오답 (질병관리청장 + 시장군수구청장)
> **함정**: "4년마다" → 오답 (매년). 4년마다는 지역보건의료계획.
> **함정**: "전수조사 원칙" → 오답 (표본조사 원칙)

#### 지역보건의료계획 (법 제7조)

| 항목 | 내용 |
|---|---|
| 수립 주체 | **시도지사** 또는 **시장·군수·구청장** |
| 수립 주기 | **4년마다** |
| 연차별 시행계획 | **매년** |

**계획 포함 사항** (5개):
1. 보건의료 **수요의 측정**
2. 지역보건의료서비스 **장단기 공급대책**
3. **인력·조직·재정** 등 보건의료자원 조달·관리
4. 지역보건의료서비스 **전달체계** 구성 방안
5. 지역보건의료 관련 **통계의 수집·정리**

**제출 흐름**:
```
시군구 → 시군구 위원회 심의 → 시군구 의회 보고 → 시도지사에게 제출
시도지사 → 시도 위원회 심의 → 시도 의회 보고 → 보건복지부장관에게 제출
```

> **함정**: 시군구가 보건복지부장관에게 **직접** 제출 → 오답 (시도지사에게 먼저 제출)
> **연계 필수**: 사회보장기본계획 · 지역사회보장계획 · 국민건강증진종합계획

   - 나. 감염병 예방·관리
   - 다. 모성·영유아 건강유지·증진
   - 라. 여성·노인·장애인 등 취약계층

## 최빈출 함정 Top 10

### 1. 급여비용 "지급" vs "심사" 주체 교환
- **지급 → 공단** / **심사 → 심평원** (가장 기본적인 함정)

### 2. 이의신청 대상 기관 교환
- 공단 처분 → **공단**에 / 심평원 처분 → **심평원**에 (서로 바꾸면 오답)

### 3. 자격상실 시점 "다음 날" vs "된 날" 혼동
- 사망·국적상실·국내 미거주 = **다음 날** / 피부양자·수급권자 = **된 날**

### 4. 보건진료소 근거법 혼동
- 보건진료소 = **농어촌의료법** (지역보건법 아님). 지역보건의료기관 4종에 포함되지 않음.

### 5. 건강실태조사 주기 vs 지역보건의료계획 주기
- 건강실태조사 = **매년** / 지역보건의료계획 = **4년마다** (서로 바꾸면 오답)

### 6. 요양기관 현황 변경 신고 기한
- **15일** 이내 (30일로 바꾸면 오답)

### 7. 요양급여비용 계약 기한 교환
- **5월 31일**까지 계약 / 미체결 시 **6월 30일**까지 장관 결정 (서로 바꾸면 오답)

### 8. 건강검진 신고 기한 · 수리 통지 · 과태료
- 신고: **10일** 전 / 수리 통지: **7일** 이내 / 위반: **300만원** 이하 과태료

### 9. 건강실태조사 방법
- **표본조사** 원칙 (전수조사 원칙으로 바꾸면 오답)

### 10. 분쟁조정위원회 소속
- **보건복지부** 산하 (공단 산하라고 하면 오답)
