| 당직 전문의 | 권역: 내외산소영마+신경/신외/정형/흉외 -- 지역센터: **내외산소마** -- 지역기관: 내과계+외과계 |

| AED 선박 기준 | 총톤수 **20톤** 이상 |

## 04-01 총칙 (용어 정의, 면책, 형 감면)

### Switch Map

| 축 | 답 |
|---|---|
| **누가** | (1) 모든 국민/외국인 (권리자) (2) 누구든지 (신고/협조 의무) (3) 선의의 응급의료 제공자 (면책 대상) |
| **누구에게** | 응급환자, 응급의료기관등 |
| **무엇을** | 응급의료를 받을 권리(차별금지, 외국인 포함), 알 권리, 신고/협조 의무 -- 면책: 고의/중과실 없으면 민사+상해 형사 면제, 사망 형사 감면 -- 형 감면: 불가피+중과실 없으면 형법 268조 감경/면제 |
| **언제까지** | 응급환자 발견 시 **즉시** 신고 |
| **예외** | 제64조: 음주 심신장애로 제12조 위반 시 형법 10조1항 적용 배제 가능 |
| **벌칙** | 종사자 형 감면은 "감경 또는 면제할 **수** 있다" (임의적) |

### 시험장 판단 문장
- "비의료인이 선의로 응급처치 -> 상해 발생" -> 고의/중과실 없으면 **민사+상해 형사 면제** (사망은 감면)
- "종사자가 업무수행 **중이 아닐 때** 응급의료" -> 비의료인과 **동일한** 면책 (제5조의2 제2호)
- "종사자가 업무수행 **중**에 긴급 응급의료 -> 사상" -> **제63조** 감면 (불가피+중과실 없음 요건)
- "음주 상태에서 응급의료 방해" -> 형법상 심신장애 감경 적용하지 **아니할 수 있다** (임의적 배제)
- "응급의료종사자" = 의료인 + 응급구조사 (**간호조무사 제외**)
- "응급의료기관" = 권역/전문/지역센터/지역기관 (**중앙응급의료센터 제외** -- 2022.12.22부터)

### 함정 패턴
1. 사망 형사책임을 "면제"라고 변형 (정답: **감면**)
2. 업무수행 중에도 제5조의2 면책 적용된다고 제시 (업무 중은 **제63조** 적용)
3. 응급의료종사자에 간호조무사를 포함 (종사자는 의료인+응급구조사**만**)
4. 중앙응급의료센터를 응급의료기관에 포함 (2022.12.22 이후 **제외**)

## 04-02 응급의료종사자의 권리와 의무

### Switch Map

| 축 | 답 |
|---|---|
| **누가** | 응급의료종사자(거부금지/우선진료/설명동의/중단금지), 의료인(이송 판단/비응급환자 조치), 의료기관의 장(이송 시 인력/장비/기록 제공), 누구든지(방해금지) |
| **누구에게** | 응급환자, 법정대리인/동행인, 이송받는 의료기관, 수사기관(방해 시 신고) |
| **무엇을** | 거부금지(제6조), 비응급환자 조치(제7조: 응급실 외 의뢰 또는 타 기관 이송), 우선 응급의료(제8조: 더 위급한 환자 우선), 설명/동의(제9조), 중단금지(제10조), 이송(제11조), 방해금지(제12조) |
| **언제까지** | 이송: **지체 없이** -- 방해 인지 시: 수사기관에 **즉시** 신고 후 시도지사/시군구청장에 통보 |
| **예외** | 설명/동의 예외: (1) 의사결정능력 없는 경우 (2) 설명/동의로 생명 위험/중대한 장애 우려 시 -- 의사결정능력 없고 법정대리인 미동행: 동행인 설명 후 의사 판단 + 의료인 1명 동의(시행규칙) |
| **벌칙** | 방해죄 -- 기본: **10년** 이하 징역 또는 **1천만~1억** 벌금 -- 중상해: **3년** 이상 유기징역 -- 사망: **무기징역** 또는 **5년** 이상 징역 |

### 시험장 판단 문장
- "의사결정능력 없는 응급환자 + 법정대리인 동행" -> 법정대리인에게 설명하고 **동의**
- "의사결정능력 없는 응급환자 + 법정대리인 미동행" -> 동행인에게 **설명** + 의사 판단으로 진료 + **의료인 1명 동의** (시행규칙 제3조3항)
- "이송 판단" 주체 = **의료인** (의료기관의 장이 아님)
- "이송 시 제공 3가지" = **의료기구 + 인력 + 의무기록** (의료기관의 장이 제공)
- "비응급환자 조치" 주체 = **의료인** (응급의료종사자가 아님)
- "방해 신고 순서" = 수사기관에 즉시 신고 -> 시도지사/시군구청장에 **통보**

### 함정 패턴
1. 법정대리인 미동행 시 "보호자 동의"라고 변형 (정답: 동행인 설명 + 의료인 1명 동의)
2. 이송 판단 주체를 "의료기관의 장"으로 변형 (정답: **의료인**)
3. 비응급환자 조치 주체를 "응급의료종사자"로 변형 (정답: **의료인**)
4. 방해죄 벌칙 숫자 뒤섞기: 중상해를 "5년 이상", 사망을 "3년 이상"으로 교차 배치

## 04-03 국가 및 지방자치단체의 책임

### Switch Map

| 축 | 답 |
|---|---|
| **누가** | 보건복지부장관(기본계획/연차별시행계획/평가/교육명령), 시도지사(지역시행계획/교육명령/결과 보고), 복지부장관+시도지사+시군구청장(종사명령) |
| **누구에게** | 중앙응급의료위원회(심의), 시도응급의료위원회, 교육 대상 15개 직종 |
| **무엇을** | 기본계획(5년), 지역시행계획(매년), 구조/응급처치 교육, 응급의료정보통신망 구축, 비상대응매뉴얼, 환자 다수 발생 시 종사명령 |
| **언제까지** | 기본계획: **5년**마다 -- 지역시행계획: **매년** -- 확정 후 통보: **지체 없이** -- 교육/홍보 계획: **매년** |
| **예외** | 기본계획 변경: 보건의료 시책상 필요 시 중앙위원회 심의 거쳐 변경 가능 -- 종사명령 거부: 정당한 사유 없으면 불가 |

### 시험장 판단 문장
- "기본계획 수립" -> **복지부장관**, **5년**마다, **중앙응급의료위원회** 심의
- "지역시행계획 수립" -> **시도지사**, **매년** (시군구청장이 아님)
- "중앙응급의료위원회" -> **15명** 이내 (보건의료정책심의위원회 25명과 혼동 주의)
- "교육 대상" -> **응급의료종사자가 아닌 사람** 중 15개 직종 (구급차 운전자, 여객자동차 운전자, 보건교사 등)
- "교육/홍보 계획 수립 시 협의 대상" -> **소방청장**
- "교육 결과 보고" -> 시도지사가 **복지부장관**에게 보고

### 함정 패턴
1. 기본계획 주기를 "3년마다" 또는 "매년"으로 변형
2. 중앙응급의료위원회를 "25명 이내"로 변형 (보건의료정책심의위원회와 혼동 유도)
3. 지역시행계획 수립 주체를 "시군구청장"으로 변형 (정답: 시도지사)
4. 교육 대상에 "응급의료종사자"를 포함 (종사자가 아닌 사람이 대상)

## 04-04 응급의료기금

### Switch Map

| 축 | 답 |
|---|---|
| **누가** | 보건복지부장관(기금 설치, 수가 기준 결정), 의료기관/구급차 운용자(대지급 청구), 심사평가원장(대지급금 심사/지급, 구상권 행사) |
| **누구에게** | 심사평가원장(대지급 청구 대상), 관계기관(자료 제공 요청) |
| **무엇을** | 기금 설치/관리, 미수금 대지급(응급환자 본인부담금), 구상권 행사, 수가 결정(평가결과 반영 차등 가능), 이송처치료 외 별도 비용 금지 |
| **언제까지** | 미수금 대지급 청구: 진료/이송 종료일부터 **3년** 이내 -- 구상권 소멸시효: 청구 가능일부터 **3년** |
| **예외** | 자료 제공 시 사용료/수수료 **면제** -- 정부 출연금: 도로교통법 과태료/범칙금 예상수입액의 **100분의 20** |

### 시험장 판단 문장
- "미수금 대지급 청구 대상" -> **심사평가원장** (복지부장관이 위탁)
- "미수금 대지급 청구 기한" -> 진료종료일 또는 이송종료일부터 **3년** 이내
- "구상권 소멸시효 기산점" -> 대지급금을 **청구할 수 있는 날**부터 3년 (지급한 날이 아님)
- "기금 재원" -> 국민건강보험법 **과징금** + 출연금/기부금 + 정부 출연금(도로교통법 과태료/범칙금의 20%) + 수익금
- "응급의료수가 차등" -> **평가 결과** 반영하여 차등 가능

### 함정 패턴
1. 대지급 청구 기한을 "5년" 또는 "1년"으로 변형
2. 청구 대상을 "복지부장관"으로 변형 (위탁받은 심사평가원장이 정답)
3. 재원 비율을 "100분의 10" 또는 "100분의 30"으로 변형 (정답: 20%)
4. 구상권 시효 기산점을 "대지급금 지급일부터"로 변형 (정답: "청구할 수 있는 날부터")

## 04-05 응급의료기관

### Switch Map

| 축 | 답 |
|---|---|
| **누가** | 복지부장관(중앙센터 설치, 권역/전문 지정), 시도지사(지역센터 지정), 시군구청장(지역기관 지정, 비지정 기관 신고 수리) |
| **대상 병원** | 권역: 상급종합 또는 300병상 초과 종합 -- 전문: 권역/지역센터 중 분야별(소아/화상/독극물) -- 지역센터: 종합병원 -- 지역기관: 종합병원 (시군은 병원 가능) |
| **무엇을** | 24시간 진료 유지, 비상진료체계(당직전문의), 예비병상 확보(허가병상의 1% 이상, 병의원 1병상 이상), 응급실 체류 제한, 출입 제한/관리, 중증도 분류, 3년마다 재지정 |
| **언제까지** | 재지정: **3년**마다 -- 응급실 체류: 24시간 초과 연 **5%** 미만 -- 출입자 명단 보존: **1년** |
| **예외** | 비지정 의료기관 응급의료시설 운영: 시군구청장에게 **신고** 필요 (단, **종합병원은 신고 불필요**) -- 재난/감염병 유행 시 지정기준 예외 인정 가능 -- 보호자 2명 동반: 소아/장애인/술취한 사람/정신질환자 |

### 응급의료기관 지정권자 비교표

|---|---|---|---|

- "권역 지정권자" -> **복지부장관** (시도지사를 거쳐 신청)

## 최빈출 함정 Top 5

### 1. 사망 형사책임 "면제" vs "감면" (제5조의2)
- **함정**: "선의의 응급의료로 사망이 발생해도 형사책임이 면제된다"
- **정답**: 상해 형사책임은 **면제**, 사망 형사책임은 **감면** (면제가 아님)
- **판별법**: "사망"이 나오면 반드시 "감면"을 고르고 "면제"는 배제

### 2. 응급의료기관 지정권자 뒤섞기 (제26조/제30조/제31조)
- **함정**: 지역응급의료센터를 "보건복지부장관"이 지정, 지역응급의료기관을 "시도지사"가 지정
- **정답**: 지역센터 = **시도지사**, 지역기관 = **시군구청장**, 권역/전문 = **복지부장관**
- **판별법**: "센터"까지는 시도지사, "기관"은 시군구청장으로 한 단계 더 내려감

### 3. 설명/동의 -- 법정대리인 미동행 시 절차 (제9조)
- **함정**: "보호자의 동의를 받아야 한다" 또는 "법정대리인의 전화 동의"
- **정답**: 동행인에게 **설명** + 응급처치 + 의사의 **의학적 판단**에 따라 진료 + **의료인 1명 동의**(시행규칙)
- **판별법**: "동행인" + "설명" + "의료인 1명" 세 키워드가 모두 있어야 정답

### 4. 미수금 대지급 청구 대상과 기한 (제22조/시행령 제20조)
- **함정**: "복지부장관에게 5년 이내 청구" 또는 "국민건강보험공단에 청구"
- **정답**: **심사평가원장**에게, 진료/이송 종료일부터 **3년** 이내
- **판별법**: 기금 관리 위탁 = 심사평가원, 기한 = 3년 (구상권 시효도 3년)

### 5. 방해죄 벌칙 숫자 교차 배치 (제12조 위반)
- **함정**: 중상해를 "5년 이상", 사망을 "3년 이상"으로 뒤섞기
- **정답**: 기본 = 10년 이하/1천만~1억 -- **중상해 = 3년 이상** -- **사망 = 무기 또는 5년 이상**
- **판별법**: 숫자 오름차순 기억 -> 3(중상해) < 5(사망) < 10(기본 상한), 사망에만 "무기"가 붙음
