# 소아청소년과 B분과 GitHub bundle 원문 분배 계획 v1

## 원칙
- **source_raw_blocks**: docx 원문을 P/T 번호 단위로 그대로 보존. UI 상세 패널/근거 팝업의 source of truth.
- **schedule_slots**: 요일/시간/장소/교수님 단위 일정 카드. 각 카드가 raw_source_refs를 통해 원문 블록을 가져옴.
- **assignment_registry**: 유폴리오/발표/서면 과제의 시작일·마감·제출위치·raw 근거를 따로 관리.
- **checklist_templates**: 우리 조 4명이 당일 체크할 행동 목록. 일정 카드에서 생성.
- **question_banks**: 혈종/신생아/감염 질문 야마를 과제/일정에 연결. 원문 표는 raw block으로 보존.
- **sensitive_flags**: 공개 GitHub Pages에 올리기 전 비밀번호/내부 보안정보/환자식별 위험 문구를 표시. B분과는 환자 실명은 없음.
