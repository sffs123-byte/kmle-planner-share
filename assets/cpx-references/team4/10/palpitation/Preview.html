l  Overview

1. ​접근: 생리적/심장/내분비/Loss/정신 생각

a. ​부정맥의 양상 파악 = C -> 심장 전도 문제의 감별

b. ​A + F -> 나머지 감별질환 문진

2. ​Ex: 이전 두근거림과 현재 증상의 원인이 다를 수 있으니 미리 판단하지 않기

3. ​심혈관계 위험인자: 순환기에서는 잊지 않기! -> 과거력/사회력/가족력/생활습관교육

4. ​신체진찰: V/S 확인, 맥박 측정 필수 + 경동맥/경정맥/심음/호흡음 동선 최적화 상기

5. ​Red flags(실신/흉통/호흡곤란) 체크

6.  ​PPI 잘 챙기기, 안심시키기 중요! - 불안/피곤/비협조적 SP 가능 ​
