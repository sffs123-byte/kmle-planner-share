11. 고혈압

● 중요 포인트
1. 정확하게 측정된 혈압인지, 검사 전 지켜야 할 사항을 잘 지켰는지 확인
2. 일차(본태) vs. 이차 고혈압 감별 – 30세 이전, 갑자기 발생한 고혈압, 잘 조절되던 혈압이 뚜렷한 이유 없이 상승되면 이차성 의심
3. 고혈압과 관련된 위험인자, 생활습관 인자 확인
4. 동반된 합병증 확인
5. 교육 – 치료받지 않을 경우의 위험성 설명, 집에서 혈압 자주 측정하기, 혈압약만으로는 혈압조절이 충분하지 않을 수 있으므로 생활습관 개선 필요
6. 정상: <120/80  // 주의혈압: 120~129/<80  // 고혈압전단계: 130~139/80~89  // 1기고혈압: ≥140/90  // 2기고혈압: ≥160/100
