43. 토혈

● 중요 포인트 2가지!

1. 객혈과 토혈을 우선적으로 감별!

2. 토혈의 양과 응급 증상 등으로 응급 처치 여부를 결정

 

● Overview

1. 병력청취

- 객혈과 토혈을 감별, 토혈의 양상

- 응급 증상 확인 + 전신, 출혈 경향성!, 소화기

- 음주 관련 질문 (말로리-바이스), 간질환 관련 질문, 식사 관련 질문 (GERD, 궤양)

2. 신체진찰 - 혈압측정, 정맥 주사, 안전 수혈 술기

- V/S 확인: 혈압 + 맥박 확인

- 코와 입에서 출혈 확인

- 손: 시진 상 이상 없는지, flapping tremor 확인!

- 전신 + 복부 + 간/비장, 복수 + DRE!

3. 교육

          - 안심: 피와 관련되었기 때문에 환자 공포감 안심시켜 주기!

          - 응급: 어지러움, 다시 피를 토함, 짜장면 같은 검은 변 시 즉시 내원 / 수액공급 및 수혈 필요성

          - 아스피린/NSAIDs(진통제) 복용 확인 후 중단

          - 내시경 교육 / 필요 시 혈관조영술, 외과적 치료

유발 요인: 식사, 과음 후 반복 구토(말로리-바이스), 약물(NSAIDs/아스피린), 간질환 병력
